# RecoverAI

AI Revenue Recovery & Churn Prevention Platform for Razorpay Merchants.

## Quick Start
1. `cp .env.example .env`
2. `docker compose up --build`
3. Open http://localhost:3000

## Features
- Multi-stage AI Agents (Risk, Strategy)
- Deterministic Policy Engine (LLM proposes, Policy controls)
- Idempotent Webhook Processing
- Simulation Lab comparing Blind Retry vs RecoverAI
- Razorpay Test Mode Integration
